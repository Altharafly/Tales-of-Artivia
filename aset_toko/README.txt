Cara susun di GDevelop: kartu kosong -> taruh ikon di tengah area atas -> Text untuk judul (di bar atas),
deskripsi (kotak krem) dan harga (kotak kuning, sebelah kanan koin) -> tombol_beli di bawah.
Kilau kuning kecil di sekitar ikon tidak dipisah (menyatu dengan latar krem).
Matikan "Smooth the image" di Game Properties agar tetap tajam.
